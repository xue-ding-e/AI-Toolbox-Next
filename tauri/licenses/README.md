# Bundled license texts

These files are **copies**, kept here so Tauri can bundle them into the
installer (`bundle.resources` in `../tauri.conf.json`). They exist only because
resource paths must resolve inside this config directory.

The canonical versions live at the repository root:

| Copy here | Canonical source |
|-----------|------------------|
| `AGPL-3.0.txt` | `../../LICENSE` |
| `GPL-3.0.txt` | `../../licenses/GPL-3.0.txt` |
| `LGPL-3.0.txt` | `../../licenses/LGPL-3.0.txt` |
| `NOTICE` | `../../NOTICE` |

If the project is ever relicensed, update both copies.
