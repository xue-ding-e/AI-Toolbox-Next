| File | Used for tool keys | Notes |
|------|--------------------|-------|
| `droid.svg` | `droid` | Factory Droid mark |
| `workbuddy.png` | `workbuddy`, `workbuddy_ai` | WorkBuddy mark; `workbuddy_ai` is the same product family and has no separate asset |
| `openclaw.svg` | `qclaw`, `easyclaw`, `autoclaw` | Generic OpenClaw-family claw mark (no wordmark); the derivatives ship no icon of their own |

The main `openclaw` tool key does NOT use this file; it renders the
`@lobehub/icons` OpenClaw component (see `ToolIcon.tsx`).
